# Extractor de Comprobantes — versión web

App Next.js que se despliega en Vercel. Las instrucciones completas (deploy, variables de entorno y cuenta de servicio de Google Sheets) están en la sección **🌐 Versión Web (Vercel)** del [README principal](../README.md).

```bash
cp .env.example .env.local   # llenar GEMINI_API_KEY, GOOGLE_SHEETS_ID, GOOGLE_SERVICE_ACCOUNT
npm install
npm run dev
```
